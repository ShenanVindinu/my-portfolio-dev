# Personal Portfolio 🥕  

This is my **personal portfolio website**, showcasing my **projects, skills, and contact information**. It highlights why you should choose me over others. Built with **HTML, CSS, and JavaScript**, the site is fully responsive and features animations using **Google Fonts** and the **Animate.css** library.  

## 🥬 Features  

  **5 Pages:**  
   -  Home  
   -  About  
   -  Work  
   -  Gallery  
   -  Contact  

✅ **Smooth animations** with Animate.css  
✅ **Google Fonts** for modern typography  
✅ **Deployed on GitHub Pages** for easy access  

## 🚀 Live Demo  

🔗 [View Portfolio](https://shenanvindinu.github.io/my-portfolio-dev/)  

## 📂 Installation  

1. **Clone the repository:**  
   ```sh
   git clone https://github.com/ShenanVindinu/my-portfolio-dev.git
   cd your-portfolio
   ```  
2. Open `index.html` in a browser to preview the site.  

## 🛠️ Technologies Used  

- **HTML** – Structure  
- **CSS** – Styling  
- **JavaScript** – Interactivity  
- **Google Fonts** – Custom typography  
- **Animate.css** – Smooth animations
